### Apply a turn's Taiga download (`changes.diff` is cumulative: always onto `sandbox-base`)

```bash
git switch -c task_N_turnX sandbox-base
git apply -p2 --check /path/to/changes.diff && git apply -p2 /path/to/changes.diff
git add -A && git commit --no-verify -m "chore(taiga): apply task N turn X"
```

Or replace files from the zip's `files/` folder (only if there's no `OMITTED.txt`, and handle deleted files):

```bash
rsync -av /path/to/<id>_X_a_changed_files/files/reactive-resume/  ./
```

## 2. In the Taiga sandbox terminal

Tools available there: **terminal, VS Code, Chrome, Node 22, pnpm 10.34.x, PostgreSQL 16 (installed, not running)**.
No Docker. Don't assume anything else is missing: check with `which <tool>`.

### Install

```bash
cd /workspace/reactive-resume
node -v; pnpm -v
pnpm install --frozen-lockfile
```

### Tests (by package; no database needed)

```bash
pnpm --filter @reactive-resume/schema test
pnpm --filter @reactive-resume/resume test
pnpm --filter @reactive-resume/api test
pnpm --filter @reactive-resume/docx test
pnpm --filter @reactive-resume/mcp test
pnpm --filter @reactive-resume/db test
pnpm --filter web test
# one file:
pnpm --filter @reactive-resume/api exec vitest run src/features/resume/pagination.test.ts
```

### Typecheck, lint, format

```bash
(cd packages/api && pnpm exec tsgo --noEmit)        # any package: packages/<name> or apps/web
pnpm exec oxlint --deny-warnings
pnpm exec oxfmt --check
```

### Postgres (integration tests / running the app)

```bash
mkdir -p /tmp/pgdata
initdb -D /tmp/pgdata -U postgres --auth=trust > /tmp/initdb.log 2>&1
pg_ctl -D /tmp/pgdata -l /tmp/pg.log -o "-p 5432 -k /tmp" start
psql -h /tmp -U postgres -c "select version();"
# integration tests:
COVER_LETTER_TEST_DATABASE_URL="postgresql://postgres@localhost:5432/postgres?host=/tmp" \
  pnpm --filter @reactive-resume/api exec vitest run src/features/resume/<name>.integration.test.ts
# stop:
pg_ctl -D /tmp/pgdata stop
```

### Run the app and use it in Chrome

```bash
cat > .env.local <<'EOF'
APP_URL=http://localhost:3000
DATABASE_URL=postgresql://postgres@localhost:5432/postgres?host=/tmp
AUTH_SECRET=local-sandbox-secret-only-for-testing
STORAGE_BACKEND=local
LOCAL_STORAGE_PATH=/tmp/rr-storage
FLAG_DISABLE_API_RATE_LIMIT=true
EOF
mkdir -p /tmp/rr-storage
pnpm db:migrate
pnpm dev                       # web :3000, API :3001, email preview :3002
```

Chrome → `http://localhost:3000` → sign up (no email verification) → try the feature. Emails print in the server log.
